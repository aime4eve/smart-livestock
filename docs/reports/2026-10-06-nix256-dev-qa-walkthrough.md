## 发现的问题

### Major（新发现，前两轮评审未命中）

**Q1 · "漏报补录"入口在空态（今日 0 事件）不可达**
- 位置：`Mobile/mobile_app/lib/features/drinking/presentation/widgets/drinking_event_list.dart:61-74`——`todayEvents.isEmpty` 时提前 return 空态文案，补录按钮在 `:116-139` 的非空分支内
- 影响：**今日一个事件都没检出时——恰恰是漏报最可能发生的场景——用户反而无法补录**。本次走查中我是先用 API 造了一条事件才让按钮出现，普通用户没有这个路径
- 建议：空态分支同样渲染补录按钮（canWrite 时），一行级修复
