## 三、精度未达判据的根因（按证据强度排序）

1. **结构性天花板：生成器渐降幅度浅**——36h 线性 −0.3℃ 在产犊前的窗级实测降幅最高 ≈0.27℃，**永远到不了体温高温档阈值 0.30℃**（Burfeind ≥0.3℃/24h 口径；文献降幅区间上限 0.4-1.0℃，本生成器取文献下沿）。窗内检出实际只依赖末 8h 活动 ×1.5 短窗 + 中档体温 + 先验的组合，命中率天然受限。
2. **信噪比边界**：个体噪声 SD 0.4℃（AR φ=0.6）下 24h 窗均值噪声 ≈0.16℃，与信号 0.2-0.3℃ 同量级（SNR≈1.25）；30min 粒度放大窗均值噪声。
3. **饮水谷残留穿透门卫**：谷底 34.1-36.7℃，[35,43] 门卫只能滤掉 <35 部分；残留样本制造假降幅 → **早触发占住 ACTIVE 状态 → 去重使真信号到窗时无法再建单 → 窗内检出被挤掉**（run32 明细实证：9/10 头有 episode 但全部在窗前）。
4. **误报方差大**（27-93/90 头/14d）：对昼夜相位与饮水排布敏感（run31 vs run35 同种子对照）。
