### 1.4 与"真实效果验收"的距离

本仿真证明的是：**评估管道、指标口径（MAE/bias/命中率/分层）、学习器对五类干扰的鲁棒性机制**。真实口径的差异项（须试点真实数据关闭）：
- 真实瘤胃温度的个体分布与昼夜形态是否与文献参数一致（D1/D5 数据集可先行核对）；
- 兽医手工校准的真实误差带（本仿真用 ±0.2℃ 代理）；
- 真实饮水检测器 F≈0.93 的漏检/误检对学习器的残余影响（本仿真用完美事件行替代）。

## 二、发情机制对比（重大方法学发现）

| 侧 | episodes | ≥70 分点 | TP | FP | FN |
|---|---|---|---|---|---|
| DEFAULT 38.50 | 0 | 0 | 0 | 0 | 6 |
| LEARNED | 0 | 0 | 0 | 0 | 6 |

**两侧全零——30min 上报粒度下，现行"最近 3 条 vs 其余 4 条"步数增幅评分对 18h 渐变型发情事件天然失灵**：增幅窗（最近 7 条≈3.5h）在事件中段全被事件覆盖（增幅≈0），仅事件边界 1–2 帧短暂抬升且远低于 70 分。两侧同样失败说明**基线不是检出瓶颈，评分算法的窗口口径才是**——这是"发情时间窗归一化"前置（NIX-158/286 前置 3）的定量实证。datagen 现有 ESTRUS 场景在 5min 粒度下可触发，恰好掩盖了该缺陷。

**含义**：真实胶囊（30min 上报）即使基线学习完美，现有发情评分也几乎不会命中。前置 3 应升级为发情检出的**阻断项**（算法需改为绝对活动水平对比或跨事件窗口），另立工单，本次不动生产评分。

## 三、分娩预警数据前置验证（达成）

产前牛数据形态已按学术口径（Costa Jr 2016：24–48h 渐降 −0.2~−0.4℃）合成并带真值标签窗：3 头 PREPARTUM 的 [产犊−48h, 产犊] 标签窗内温度呈线性渐降（−0.3±噪声）、末 8h 活动指数 ×1.5——序列可被未来 `CalvingPredictionService` 直接消费（输入面=学习器同款窗口查询 + 标签窗对齐）。**数据充分性结论**：RBC 体温通道 + 活动通道（含步数派生）足以承载"体温渐降+活动变化"双信号产前算法；步数在仿真中由活动强度派生，真实胶囊的步数/活动派生（前置 2）仍需固件/平台侧落地。

## 四、执行中抓到并修复的缺陷

1. **Composer 时区缺陷**（dev 实测抓到）：日相按 UTC 而非牧场本地时区 → MAE 0.47 的系统性负偏 → 修复为 farm 本地日相后收敛至 0.148。单测补跨时区断言（12 项）。
2. **生成器缺快照建档**：30 头无 health_snapshots 行导致学习器全部跳过 → 生成器补 `ensureSnapshotExists`（语义=真实遥测落库后消费链自动建档，直插必须补齐）。
3. **温谷缺 drinking_events**（远程 Journey 抓到）：学习器饮水排除无输入 → MAE 1.69 → 生成器补写事件行（模拟 F≈0.93 检测器输出）→ 0.47。
4. **ScenarioType 兼容缺口**（评审抓到）：新 PREPARTUM/ILLNESS 标签会被现有 `/admin/datagen/evaluation` 误当 AI 异常正例 → 加 `isSimulationOnly()` 排除。
