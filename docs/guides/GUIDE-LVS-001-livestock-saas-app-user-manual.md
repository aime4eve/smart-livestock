# 智慧畜牧平台 用户手册

> **版本：** v1.1（Draft，2026-11-21——告警口径校真：状态流改为 V26 三态模型（标记已读/关闭，含自动解除）、补 APNs 推送口径（默认关）、产犊预警改临产评分口径；v1.0：2026-09-19 初版）——中文正本，待市场/产品审核后作为英文版翻译底稿；**审核通过前不外发**。
> **适用对象：** 牧场主（owner）、牧工（worker）及牧场管理人员
> **适用产品：** 智慧畜牧解决方案软件平台（Web 管理端 + 手机 App），配合 GAT-100 牛羊追踪器、RBC-100 瘤胃胶囊与 LoRaWAN 网关使用
> **资料来源：** 平台培训手册 v1.0、技术支持手册 v1.1、GAT-100/RBC-100 培训手册 V1.1

## 1. 系统简介

智慧畜牧平台把设备数据变成牧场日常工作：**牲畜档案、实时地图、电子围栏告警、健康趋势、订阅管理和开放接口**。

```text
GAT-100 牛羊追踪器（项圈佩戴）→ 位置、步数、运动量、电量
RBC-100 瘤胃胶囊（投服进瘤胃）→ 瘤胃温度、胃动力、活动量
LoRaWAN 网关 → 设备数据接入与转发
智慧畜牧平台 → 绑定牲畜、地图、围栏、告警、健康分析
手机 App / 网页管理端 / Open API → 牧场主、牧工、集团管理员、第三方系统
```

**它能帮您：** 随时知道牲畜在哪里；牲畜越界时收到告警；通过体温/胃动力/活动量趋势更早发现健康异常个体（辅助提示，不替代兽医诊断）；多牧场、多角色协同。

## 2. 快速上手（第一次使用）

1. **登录**：打开 App 或管理端网址，输入管理员发放的手机号和初始密码。**首次登录会强制要求修改密码**，设置您自己的密码后即可正常使用。
2. **选择牧场**：一个账号可能被分配多个牧场，切换牧场后页面数据自动刷新。您只能看到被分配牧场的数据。
3. **设置时区**：进入"我的"页确认时区设置正确——界面显示的时间、日/小时统计都按这个时区显示；跨时区远程查看（例如在国内看海外牧场）显示的是**查看方**的时区，属正常设计。
4. **确认设备在线**：在设备或牲畜页面查看设备最后上报时间和电量。设备默认约 30 分钟上报一次，刚上线请耐心等待一个上报周期。

## 3. 账号与角色

| 角色 | 能看到什么 | 能做什么 |
|---|---|---|
| 牧场主 owner | App 全部业务页、后台、牧工管理、订阅 | 管理牲畜、围栏、设备、告警的标记已读/关闭、订阅 |
| 牧工 worker | 地图、告警、围栏、我的 | 查看地图和告警，可**标记已读**并**关闭**告警 |
| 集团管理员 b2b_admin | B 端控制台 | 管理旗下牧场、牧工、合同、对账（牧场由集团管理员或平台管理员创建并分配，不是牧场主自建） |
| 平台管理员 platform_admin | 平台后台 | 管理租户、用户、合同、订阅、API 授权 |

- **改密码**：登录后在个人设置中修改。
- **忘记密码**：联系贵方平台管理员重置；重置后首次登录同样需要改密。
- **登录提示 token 过期**：重新登录即可；提示无权限（`AUTH_FORBIDDEN`）说明当前角色无该页权限，对照上表确认。

## 4. 地图与轨迹

- **地图概览**：查看牧场范围、每头牲畜的最新位置和设备状态。
- **历史轨迹**：选择牲畜和时间范围回放位置历史。轨迹长度受数据保留策略和订阅层级影响。
- **离线地图**：在地图管理页下载牧场所在区域的离线包，弱网/无网时仍能看图。注意：**离线地图解决"看地图"，设备无网时数据上传仍受网络限制**，两者不是一回事。
- **底图说明**：底图按客户端时区自动选择——中国时区默认高德地图，其他时区默认 OSM。如果发现"地图变了"，先检查"我的"页的时区设置，这不是故障。
- **位置精度预期**：牲畜位置来自项圈按周期上报的 GPS，开阔静态环境误差约 10 米内，运动中约 20~40 米，密林遮挡更大。平台已自动过滤明显漂移点。**请不要把位置当实时视频看**——默认 30 分钟一个点，这是电池 3 年寿命的平衡设计。

## 5. 牲畜档案

一头牲畜的档案建议包含：耳号/编码/品种/性别、绑定的设备（安装记录）、最新位置、历史轨迹、体温趋势、胃动力趋势、活动量趋势、告警记录。

- **建档**：手工录入或批量导入耳号等基础信息。
- **绑定设备**：设备必须通过"安装关系"绑定到牲畜，平台才能把设备数据归属到这头牛/羊。**只注册了设备、没建安装关系的，平台不会形成个体档案**——这也是"轨迹为空"最常见的原因。
- **解绑**：牲畜转卖、设备复用时，在牲畜详情页解绑设备；解绑后历史数据仍保留在该牲畜名下。
- **查找**：牲畜较多时支持按耳号等条件搜索，列表分页加载。

## 6. 设备使用与日常维护

### 6.1 GAT-100 牛羊追踪器（项圈）

- **佩戴**：像戴项圈一样挂在牲畜颈部，带扣调节松紧（经验：能伸入 1~2 指），太松易挂蹭、太紧影响采食。
- **开关机与提示音**（电话排障必知）：

| 操作 | 反馈 |
|---|---|
| 关机状态长按按键 3 秒 | 开机，一声短鸣 |
| 开机状态短按 | 绿灯亮 |
| 开机状态长按 3 秒 | 关机，一声长鸣 |
| 入网成功 | **三声短鸣** |
| 开机状态 10 秒内连按 7 次 | 恢复出厂（红绿 LED 同亮 3 秒 + 两声短鸣），需重新入网 |

- **上报与电池**：默认 30 分钟上报一次位置/步数/运动量/电量；上报周期可远程配置（10 分钟~24 小时，周期越短电池消耗越快）。电池约 3 年免换（默认周期下），可更换。
- **防护**：IP67，雨天放牧无虞。
- **常见现象**：某次上报缺位置（设备在牛棚/遮挡处 GPS 未定位成功）属正常设计；设备连续发送失败约 5 次后会自动重入网，通常 30 分钟内自愈，期间平台看不到数据。

### 6.2 RBC-100 瘤胃胶囊（投服）

- **投服**：由兽医用投服枪经口腔送入瘤胃，**进入后不可取出、不可复用**，电池约 5 年（不可更换）。
- **投服前必做**：①核对胶囊数量与牛只数；②全程 23℃ 以下阴凉存放，**投服前不要打开包装瓶密封盖**（提前受热会激活耗电）；③逐只"温水验活"确认能发数；④**每投一只，将胶囊编号与牛耳号拍照登记**；⑤投服枪每投一只消毒一次；⑥完成后核对平台在线数 = 投服数。
- **工作方式**：进入牛胃（温度 >24℃）自动进入工作模式，按周期上报瘤胃温度、胃动力、活动量；离体/低温时自动省电。掉线期间的温度会缓存，恢复后自动补传。
- **看数据**：健康页面查看体温曲线（正常在 38~40℃ 区间）和胃动力趋势。

### 6.3 设备离线怎么判断

| 现象 | 最可能原因 |
|---|---|
| 单个设备离线 | 还在上报间隔内 / 电量耗尽 / 走出网关覆盖 / 重入网中 |
| 批量设备离线 | 网关离线或断电、网络故障 |
| 只有位置缺、其他数据正常 | 牲畜处于遮挡处，GPS 未定位（正常设计） |
| 胶囊温度不在 38~40℃ | 刚投服还在升温；或投服失败未入胃（核对登记照片） |

## 7. 电子围栏与告警

- **建围栏**：在地图上圈定放牧范围。围栏是业务规则不是画着好看的线——建好后平台按每个上报位置自动判定。
- **三种状态**：Safe（正常）、Approaching（接近边界缓冲区）、Breach（越界）。越界自动生成告警。
- **告警状态流**（V26 三态模型）：`ACTIVE → DISMISSED（人工关闭）` 或 `ACTIVE → AUTO_RESOLVED（条件消解自动解除）`。标记已读对任意登录用户开放；关闭（dismiss，单条/批量）需 owner / worker / b2b_admin，全程留痕可追溯。
- **告警通知**：告警可经 iOS 推送（APNs）触达牧工——需用户在 App 内开启推送开关且平台按环境启用（总开关默认关闭）；Android 推送在路线图。App 内告警列表始终为准。
- **没收到告警？** 依次确认：告警是否已生成 → 当前角色是否有权限 → 是否开启推送开关/通知渠道配置 → （通知渠道与响应时效按订阅合同约定）。

## 8. 健康监测

| 方向 | 数据基础 | 用途 |
|---|---|---|
| 发热预警 | 瘤胃温度趋势 | 辅助发现体温异常个体 |
| 消化分析 | 胃动力趋势 | 辅助判断瘤胃活动变化 |
| 发情识别 | 温度、活动、行为趋势 | 提示可能发情个体，需人工确认 |
| 临产预警 | 体温降幅、活动倍数、配种先验综合评分 | 临产风险评分达到阈值且持续确认时预警（评分制，非固定提前小时数），便于备产 |
| 行为分析 | 步数、加速度、位置 | 异常行为提示 |

**重要边界**：健康分析是**辅助提示工具**，不构成诊断结论，最终判断请结合现场观察和兽医意见。刚起身的牲畜前几步可能不计入步数，属正常防误计设计。

**看不到健康功能？** 健康分析依赖对应设备数据（如体温评分需要瘤胃胶囊），且部分高级功能按订阅层级开放——免费/基础版下功能入口会隐藏或显示升级提示，数据保留期也会缩短（降级不清除数据）。

## 9. 常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 登录不上 | 确认网址/入口正确 → 密码是否被锁（首登强制改密）→ 仍不行找管理员，记录页面错误码 |
| 轨迹/列表为空 | ①牧场切换是否正确 ②该牲畜是否有绑定的设备安装关系 ③查询时间范围与客户端时区 ④仍为空报修（附时间范围截图） |
| 地图不显示 | 在线模式看其他页面是否正常；离线模式确认已下载覆盖牧场的离线包；底图突然变化先查时区设置 |
| 时间和当地对不上 | "我的"页时区设置；跨时区查看显示的是查看方时区（正常） |
| 设备离线 | 见 §6.3；确认电量、最后上报时间、网关状态 |
| 告警没有通知 | 告警是否生成 → 角色权限 → 通知渠道配置 |
| 功能入口消失/提示升级 | 多为订阅层级边界（免费/基础版），联系商务升配；数据不会因降级删除 |
| 历史数据能留多久 | 与订阅层级和合同相关，不承诺无限保留 |
| 能接入我的管理系统吗 | 可以，通过开放 API（API Key + 数据范围授权 + 调用限流），联系商务开通 |
| App 打不开/提示过期 | iOS 版本目前为限量试点分发，描述文件到期需联系我方重新安装；日常请优先使用 Android App 或网页端 |

## 10. 报修前自查与报修要素

**自查四步**：①换一台手机/换网络试（判断是不是自己网络）→ ②其他用户是否正常（个别 vs 全员）→ ③核对账号角色与订阅状态 → ④重启 App 再试。

**报修请提供**：账号角色、操作时间、所在页面、问题现象截图或录屏、相关牲畜号/设备编号、期望结果。涉及数据问题请注明时间范围。这些信息能大幅缩短定位时间。

## 11. 术语表

| 术语 | 含义 |
|---|---|
| 租户 Tenant | 客户组织，数据与订阅归属单位 |
| 牧场 Farm | 业务数据范围单位，账号按牧场分配权限 |
| 安装关系 | 设备与牲畜的绑定记录，数据归属个体的依据 |
| 围栏 | 在地图上圈定的电子边界，越界触发告警 |
| 告警流转 | ACTIVE → DISMISSED / AUTO_RESOLVED 的三态状态流（V26） |
| FeatureGate | 按订阅层级控制功能可见性/数量上限/数据保留 |
| Open API | 面向第三方系统的数据接口（API Key 认证） |
| LoRaWAN | 设备与网关之间的低功耗远距离无线通信技术 |
| OTAA / ABP | 两种设备入网方式：追踪器用 OTAA（需入网），胶囊用 ABP（直接广播） |
