## 五、运维操作

### 5.1 部署 / 启动

**一键部署（日常方式，本地 Mac 执行）：**

```bash
cd smart-livestock-server
./scripts/deploy.sh test   # 部署 test（:18080）
./scripts/deploy.sh dev    # 部署 dev（:19080）
```

流程：编译 bootJar → rsync 同步（`.env`/`.env.dev` 不覆盖，远程手动维护）→ 远程 `docker compose build app ai-platform nginx && up -d` → 同步瓦片数据 → 清理悬空镜像。

**服务器上手动操作（SSH 登录 172.22.1.123 后）：**

```bash
cd ~/smart-livestock-server

# test 环境（dev 把 .env→.env.dev、compose 文件换 dev 版、项目名换 sl-dev）
DC="docker compose --env-file .env -f docker-compose.test.yml -p smart-livestock-server"

$DC up -d                 # 全栈启动
$DC up -d --build app     # 重建并重启后端
$DC restart app           # 重启单个服务
$DC stop app && $DC start app
$DC ps                    # 查看状态（应全部 Up/healthy）
$DC down                  # 停止整个 stack（⚠️ 勿加 -v，会删数据卷）
```

### 5.2 查看日志

```bash
cd ~/smart-livestock-server
DC="docker compose --env-file .env -f docker-compose.test.yml -p smart-livestock-server"

$DC logs --tail 200 app          # 后端业务日志（授权、ingestion、Flyway）
$DC logs -f app                  # 实时跟踪
$DC logs --tail 200 nginx        # 接入层
$DC logs --tail 200 postgres     # 数据库
$DC logs --tail 200 ai-platform  # AI 行为分析
$DC logs --tail 200 tile-worker  # 瓦片渲染

# 或直接按容器名
docker logs -f smart-livestock-server-app-1      # test 后端
docker logs -f sl-dev-app-1                      # dev 后端
```

排查关键字：`Flyway`（迁移成败）、`GPS ingestion task`（GPS 写入 outbox）、`license`（授权校验）、`Nacos`（远程配置拉取 outcome）。

### 5.3 健康检查与巡检

```bash
# 应用健康（200 即正常）
curl -s http://172.22.1.123:18080/api/v1/actuator/health    # test
curl -s http://172.22.1.123:19080/api/v1/actuator/health    # dev

# 登录冒烟（验证种子账号可用）
curl -s -X POST http://172.22.1.123:18080/api/v1/auth/login \
  -H 'Content-Type: application/json' -d '{"phone":"13800138000","password":"123"}'

# 资源巡检
docker ps --format 'table {{.Names}}\t{{.Status}}'   # 容器状态
df -h / /data                                        # 磁盘（重点看 /data）
docker system df                                     # docker 占用
```

磁盘维护（非破坏性）：`docker builder prune -f`、`docker image prune -f`。

### 5.4 应急操作

```bash
# 数据库直连
docker exec -it smart-livestock-server-postgres-1 psql -U postgres -d smart_livestock   # test
docker exec -it sl-dev-postgres-1 psql -U postgres -d smart_livestock                   # dev

# 平台管理员密码应急重置（服务器上执行，临时密码≥10位含字母数字，下次登录强制改密）
sudo bash scripts/reset-admin-password.sh <手机号> <新临时密码>

# 本地 Mac 直连远程 DB 排障（建 SSH 隧道）
./scripts/db-tunnel.sh
```
