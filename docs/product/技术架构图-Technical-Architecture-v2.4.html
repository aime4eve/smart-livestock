按「客户端接入 → 领域划分 → 领域间关系 → 基础 IT 建设 → 设备与外部接入 → 部署逻辑拓扑」六层呈现；按 2026-11 代码基线 as-built 绘制，规划未实现项以虚线标注

① 客户端接入层—— 所有客户端经统一入口 nginx 进入，双轨认证 + SSE 实时推送
Flutter Web（主渠道）

单一 Flutter Web 应用，nginx 静态托管 SPA 回退（try_files → /index.html）。App 内路由：/ 孪生首页 · /ops/admin 平台后台 · /b2b/admin B 端控制台（61 条路由，同一代码库）。PWA 禁用（防 service worker 回吐旧包），main.dart.js no-cache + gzip（5MB→1.2MB）

移动 App（iOS / Android）

与 Web 同一 Flutter 代码库。Android：APK 由登录页 /downloads/ 直下；iOS：TestFlight 渠道（正式开发者签名，构建 90 天有效）。API 地址经 --dart-define=API_BASE_URL 指向各环境 /api/v1

第三方系统（Open API）

/api/v1/open/* 独立端点组：牲畜/围栏/告警/设备/GPS/遥测查询 + 设备批量自注册 + 到期租户 GDPR 导出。API Key 认证（SHA-256 哈希校验），频率限制按 Key 分钟级 + 日配额

双轨认证

JWT（用户态）：Access 1h + Refresh 7d；Token 内 tid → TenantContext（ThreadLocal）→ 数据库 tenant_id 强制隔离。API Key（第三方）：不设租户上下文，由 Key 关联租户在应用层过滤。超管上下文切换 = 重签 act 标记 Token + 审计

SSE 实时信号流

POST /farms/{id}/signals/stream-ticket 领一次性票据 → GET /stream（text/event-stream）建立长连接；10 类事件（位置/瘤胃指标/告警/围栏/健康/AI 评估/设备/安装/牲畜）。nginx 专用 location 关闭缓冲、读超时 120s

系统离线推送规划未实现

APNs / FCM 离线推送、SMS、邮件汇总均未实现；当前实时性依赖 SSE + 站内通知表拉取

PostgreSQL 16自建加固镜像

业务库 + 5 张时序分区表（temperature · rumen_motility · activity · telemetry · anomaly_scores，按月分区由 PartitionMaintenanceService 每日 02:10 自动预建）；Flyway 117 个迁移版本化；数据保留治理（时序 30 天 / API 日志 90 天）；ai_reader 只读账号供 AI 平台

Redis 7

三大用途：业务热点缓存（告警/牧场总览/个体基线学习）· Open API 限流（Lua 滑动窗口：分钟频率 + 日配额）· AI 告警去重（每头 1 次/小时）

RocketMQ 5.1

NameServer + Broker 两容器承载 16 个跨域 topic（dev/test 附 Dashboard）；不可用时事件发布静默跳过，保证应用可启动

tileserver-gl 瓦片服务

10 个牧场区域 MBTiles 离线瓦片（长沙/内蒙古/东非/澳洲/阿根廷/巴西/印度等）；nginx /tiles/ 反代 + 404 透传供前端降级 OSM

tile-worker 瓦片生产

轮询 app API 领取瓦片任务，按牧场 bbox + 16km 缓冲生成新 MBTiles 写入共享卷——离线地图按需生产，不用预置全球瓦片

nginx 反向代理

全栈唯一宿主入口：静态 SPA 托管 + /api/v1 反代 + /tiles/ 反代 + SSE 专用 location（关缓冲/120s）+ gzip；release 栈 80 全局 301 → 443 TLS 终止（TLSv1.2/1.3，证书挂载 secrets/certs）

ai-platform（Python 微服务）

FastAPI + scikit-learn，容器 :8000 仅内网；L1 无监督异常检测 + 行为模型训练/评估；ai_reader 只读 PG；behavior-models 独立卷持久化模型

Nacos 配置中心仅 dev/test

blade 地址等环境配置启动期 HTTP v1 拉取（自建 NacosRemoteConfigLoader，弃官方 gRPC starter）；优先级 OS env > Nacos > application.yml；release/ONPREM 不依赖

监控（Prometheus）

经 app 直连端口（dev 19081 / test 18081，nginx 不转发）抓取 /actuator/prometheus，接入 sp-monitoring 监控栈（Grafana/Alertmanager）
