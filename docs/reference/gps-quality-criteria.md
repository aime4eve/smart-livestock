# GPS 质量检查判断标准

> 口径来源：当前后端实现，不含规划中的阈值调整。

## 静态质量检查（STATIC）

静态检查以一个 RTK 真值点为基准，逐点计算设备上报 GPS 到该真值点的 Haversine 距离。

### 有效样本

- 报告默认 `excludeSuspect=false`：全部 GPS 点参与统计。
- `excludeSuspect=true`：排除 `stepNumber > 0` 的可疑点。
- 设备统一摘要调用静态报告时使用 `excludeSuspect=true`。

### 统计指标

- 误差：GPS 点到 RTK 真值点的 Haversine 距离。
- `P50`：有效点少于 5 个时取最大误差。
- `P95`：有效点少于 20 个时取最大误差。
- `P99`：仅有效点不少于 100 个时输出。
- 抖动直径：有效点之间的最大两两距离；超过 500 点时先计算凸包再取最大两两距离。
- 离群点阈值：
  - 有效点少于 100 个：`max(3 * P95, 30m)`。
  - 有效点不少于 100 个：`max(P99, 3 * P95, 30m)`。
- 15m / 25m / 40m 占比只作为分布展示，不直接决定评级。

### 评级规则

| 条件 | 评级 |
|---|---|
| 有效点少于 10 个 | `UNAVAILABLE` |
| `P95 <= 15m` 且有效点不少于 20 个 | `EXCELLENT` |
| `P95 <= 25m` 且有效点不少于 20 个 | `USABLE` |
| `P95 <= 40m` 且有效点不少于 10 个 | `MARGINAL` |
| 其他情况 | `UNAVAILABLE` |

## 线路质量检查（LINE）

线路检查以标准轨迹折线为真值，逐点计算设备 GPS 到折线最短线段的距离。线路检查不按时间配对；时间只用于切断行程。

### 有效行程筛选

1. 点到标准折线的最短距离不超过 100m，视为在线路走廊内。
2. 相邻在线点时间间隔超过 300 秒，切断为不同行程。
3. 点离开 100m 走廊，也切断当前行程。
4. 少于 4 个点的行程被丢弃，不参与统计。
5. 统计只在保留下来的有效行程点上计算。
6. `tripCount` 为保留下来的有效行程数量。

### 统计指标

- 误差：GPS 点到标准折线的最短距离。
- `P50`：有效样本少于 5 个时取最大偏差。
- `P95`：有效样本少于 20 个时取最大偏差。
- 15m / 25m / 40m 占比只作为分布展示，不直接决定评级。

### 评级规则

| 条件 | 评级 |
|---|---|
| 有效样本少于 4 个 | `UNAVAILABLE` |
| `P95 <= 15m` 且有效样本不少于 10 个 | `EXCELLENT` |
| `P95 <= 25m` 且有效样本不少于 6 个 | `USABLE` |
| `P95 <= 40m` 且有效样本不少于 4 个 | `MARGINAL` |
| 其他情况 | `UNAVAILABLE` |

## 共同口径

- `P95` 是唯一的误差评级指标；`P50`、最大误差、占比和行程数不直接决定评级。
- 个别超过 40m 的误差点是允许的，只要这些点不足以把 `P95` 推高到 40m 以上。
- 评级顺序由高到低为：`EXCELLENT`、`USABLE`、`MARGINAL`、`UNAVAILABLE`。
