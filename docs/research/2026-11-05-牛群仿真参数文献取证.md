## 三、只能定性/反推的项（显式标注）

| 项 | 处理 | 依据 |
|---|---|---|
| 离体/环境温度样本形态 | 仿真取 25–35℃ 昼夜摆动（谷底低于门卫 35–43 下界被剔除、峰点恰达下界亦按 plausibility 通过）为唯一实现；高温环境 36–38℃ 高活动段为可选后续项，本次未实现；标注"反推" | 无专门文献；弹丸量程 20–60℃（smaXtec 规格 ★） |
| 挤奶伪影幅度 | 双峰对齐挤奶时刻、幅度按昼夜振幅的 ~50% 合成；标注"反推" | Montes 2023 双峰结构有证、幅度无数值 |
| 手工校准基线误差带 | 3 天×凌晨 3 点均值 → 个体内 SD/√9 ≈ ±0.15–0.25℃；标注"按 P2 推导，非直接文献值" | 无"连续 3 天凌晨测温"直接文献（兽医惯例） |

## 四、两处口径纠偏（防再犯）

1. **"饮水恢复 ~103min"** 是 Cantor 2018 灌服实验极端工况（22.7L @1.7℃）的恢复时间 103.3±9.5min，**不是均值**（观察期自然饮水恢复 57.75±38.70min）。仿真恢复窗取 30–120min 区间。
2. **"产犊前约 15 小时预警"** 是 smaXtec 商业宣称（机制=产前 12–15h 内部温度降 0.5–1.0℃），**无同行评审验证**；学术口径为 Costa Jr 2016（RRT 产前 24–48h 开始降 −0.2~−0.4℃）。仿真产前形态按学术口径合成；对外文档不得把 15h 当文献值。

## 五、合成公式（生成器实现基准）

```
RRT(t) = μᵢ                                   # P1，每头真值基线
       + 0.4·cos(2π(t − 23.5h)/24h)           # P3/P4 昼夜
       + 挤奶双峰伪影(反推，幅度≈0.2℃×2 峰)     # P5
       + AR(1) 噪声(φ=0.6, SD=0.4)            # P2
       + Σ 饮水温谷(深度 U(2.3,4.9), 指数恢复 30–120min)  # P7
       + THI 项(斜率 0.02·max(0,THI−65))       # P14
       + 事件调制(发情 +0.55 / 产前 −0.3 渐降 / 疾病 +0.8)  # P9/P11/P16
活动(t) = 昼夜形态(白天高) × (1 + 事件倍数)        # P8/P13
步数(t) = 活动强度派生(仿真数据充分性验证用)        # 前置 2
真值基线 = μᵢ（生成时已知）；手工校准代理 = μᵢ + ε~N(0, 0.2)
```
