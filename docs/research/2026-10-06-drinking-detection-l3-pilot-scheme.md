# 饮水行为检测 L3 试点方案（NIX-256 Task 7.3，水表/摄像头 96h 金标准）

日期：2026-10-06 ｜ 状态：方案（待立项）｜ 前置：L1（Aubé 标定，F=0.928@5min 生产口径）+ L2-pre（30 天仿真回放全链路）已完成；L2-real 顺延中（触发条件见 L2-pre 报告 §5）

## 1. 目的

获取**真实牛群、真实设备**的饮水事件金标准真值，完成检测效果的最终验收（L3）。在此之前，对外准确率口径一律为"试点验证方案"（AGENTS 红线：仿真/文献结果不混充生产效果）。

移植范本：Aubé 2025（DOI 10.57745/H2SPNR）——28 头泌乳牛 × 96h × 5-min 瘤胃温度 + 730 个视频标注饮水 bouts，是我们 L1 标定的数据形态来源。

## 2. 试点设计

### 2.1 样本与时长

| 项 | 取值 | 依据 |
|---|---|---|
| 牧场 | 1 个合作试点牧场 | 安装/标注人力集中 |
| 牛只 | 8–12 头泌乳牛（健康、瘤胃胶囊在位 ≥2 周） | Aubé 28 头缩样；按 L1 Se≈0.87/PPV≈1.0，每头日均 6–8 bouts → 96h 约 2,000–3,700 bouts（8 头），Se/PPV 置信半宽 ≤2pp |
| 时长 | **96h 连续 × 2 轮**（间隔 ≥7 天） | 覆盖工作日/周末与日节律两段；Aubé 单段 96h |
| 采样 | 胶囊 5-min 上报（现网 TB 通道确认） | 平台有效分辨率档（L1 结论：5/6-min 过门禁，10-min 0.8484 不承诺） |

### 2.2 金标准双通道（互补，不一致时以人工视频裁决）

1. **水表**：饮水点加装流量脉冲水表（每栏位 1 只，或共用总表+分栏视频辅助），记录每次饮水开始/结束/饮水量——提供时刻真值 + 量级参考（检测**不承诺饮水量**，量值仅用于一致性佐证）。
2. **摄像头**：饮水点固定机位 2 台（覆盖水面与牛头侧位），96h 连续录像；人工标注协议仿 Aubé：`bout 开始 / 结束 / 持续时长 / 段内饮水次数`（Aubé 的 DB_* 字段语义），标注工具用时间轴逐帧段标记。

双通道交叉：水表脉冲时刻 vs 视频 bout 时刻偏差 >2min 的样本进入复核队列。

### 2.3 数据治理（硬性）

- 试点牲畜打 `pilot` 标签（livestock note 或专门字段，实现时定）；试点窗内数据 source 保持真实通道（THINGSBOARD），**禁止 DATAGEN 混入**。
- 金标准标注经 **MANUAL_IMPORT source** 导入独立真值集（复用 T6 工具链：truth.csv 同构格式），不写入 temperature_logs / drinking_events。
- 结束后：真值集 + 试点窗声明归档 `output/drinking-l3/`；牧场数据快照按 AGENTS §2 恢复条款处理。

## 3. 分析协议（全部复用既有工具，零新开发）

1. 检测端：平台批算产出事件（生产参数 S=0.06/k=0.5/R=0.7/gap=15）。
2. 匹配：`calibrate.py` 四步匹配协议（±30min 关联 → 漂移校正 → ±10min 匹配 → 最近者胜出）。
3. 指标：Se / PPV / F（主指标）＋逐日频次 Bland-Altman 一致性 ＋频次量级对照 Cardot 7.3±2.8 次/日（泌乳牛）。
4. 分层：按牛只/昼夜/轮次分层报告，识别个体异质性（若个体间参数敏感度差异大 → 触发 spec §15.4 的分档调参路径，即 --labels 逻辑平移为平台任务的条件之一）。

## 4. 验收建议线（立项时定稿）

| 指标 | 建议线 | 说明 |
|---|---|---|
| F（真实数据） | ≥0.85 | 低于 L1 的 0.928 属预期（真实通道噪声/个体差异） |
| Se | ≥0.80 | 漏检主要来源=浅谷与合并近邻对（L2-pre FN 分解已量化） |
| 频次偏差 | 日均 −15%~+15% | 面向"日均次数"业务口径 |
| 未达标处置 | 回 spec §14 参数复审（--labels 真值网格）或判据结构修订 | 不带病对外 |

## 5. 物料与人力估算

- 水表 2 只（脉冲输出型，需防水安装）＋摄像头 2 台（户外防水/存储 4 天）＋线缆支架。
- 标注人力：约 40 人时/96h（视频 1.5× 实速回放 + 复核）。
- 现场协调：安装 0.5 天 + 开跑检查 0.5 天 + 拆收 0.5 天。

## 6. 风险与开放问题

- 牛只个体饮水形态差异（浅啜 vs 深饮）→ 分层报告兜底。
- 水温季节效应（冬季谷深变浅）→ 试点选常温季，L3 后参数随 --labels 季度复标。
- 水表安装是否影响饮水行为（新异物回避）→ 预跑 48h 适应期再计窗。
- 牧场网络中断 → 胶囊本地缓存确认（与固件组核对补传语义）。
- **开放**：水表型号/合规采购、标注人员来源、试点牧场人选——立项时三项待定。
