# 工单备忘：订阅健康度临期阈值可配置化

> 来源：2026-10-31 spec §7 开放问题用户裁决（NIX-324 后续）。
> 状态：待排期，未获批编码（AGENTS §3 硬性规则）。

## 裁决内容
订阅健康度横幅临期分级阈值 14/7/3 天由硬编码常量改为**平台级可配置**。

## 现状
- 判定器：`SubscriptionHealthEvaluator`（commerce 域，NIX-324 Task 1），阈值硬编码。

## 验收要点
- 默认值 14/7/3 与现行为一致（种子迁移不改现行表现）。
- 修改阈值后判定矩阵 #1–#7 与 daysToExpiry 边界回归。
- 与 NIX-323 Resolver / NIX-325 Policy 三组件机械核对口径不破。
