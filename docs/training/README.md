## 方案口径

智慧畜牧解决方案由以下部分组成：

1. GAT-100 牛羊追踪器：位置、步数、三轴加速度。
2. RBC-100 瘤胃胶囊：瘤胃温度、胃动力、三轴加速度。
3. LoRaWAN 网关与网络服务：频段、覆盖和数据转发。
4. 智慧畜牧软件平台：设备绑定、牲畜档案、地图、围栏、告警、健康分析、订阅和 Open API。
5. 实施与服务（远程指导）：现场勘测、安装/投服、配置、培训和售后支持。

任何客户承诺都必须同时说明设备、网络、数据、平台和实施前置条件。
