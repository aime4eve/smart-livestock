疫情应急处置

接触追踪记录呈现 · 3 套高保真方案

三套方案共用同一套风险语义与设计令牌。差异在于：A 让接触事件更易分诊，B 让处置对象更明确，C 让传播路径更可调查。

最终建议 · A + B + C 三视图统一体验原型 以处置为默认入口，记录用于证据核查，链路用于扩散调查。三套视图共享风险模型、筛选条件和跨视图跳转。

方案 A

风险分诊记录流

保留接触事件列表，但按风险分数、时间窗口和成因重排，适合最快的记录层改造。

  • 高/中/低风险数量前置
  • 24h / 48h / 72h 观察窗口
  • 每条记录解释风险成因

方案 B · 推荐

牛只处置分级视图

把多条接触记录聚合为“先处理哪头牛”，直接匹配隔离、观察和复核决策。

  • 一级 / 二级 / 三级处置队列
  • 接触数与最高风险聚合
  • 保留可展开的原始证据

方案 C

传播链调查视图

以疑似源头为中心展示第一层接触和高风险路径，适合需要判断扩散方向的调查场景。

  • 源头与一阶接触图形化
  • 高风险传播路径单独提示
  • 原始记录作为证据留存

选型建议

若以疫情应急处置为核心，优先选 B；B 可以吸收 A 的记录行样式作为展开证据。C 更适合二期增强，因为多跳传播链需要后端与图交互能力支撑。

实施前需要后端补齐接触时长、时间差、风险等级/分数，并提供牛只聚合数据；当前 overview 只返回前 20 条记录，前端不应自行硬算风险。
