B 围栏图鉴（暗色仪表盘）极高：发光多边形 + 扫描线动画低-中：单屏 3-4 块中：保留告警语言，形态独立演示/巡检场景，围栏形状空间记忆最强，"爆款"观感
C 牧场沙盘（畜群分布）高：活体点阵 + 脉冲告警中：单屏 3-4 片沙盘强：浅色地形延续牧场基调畜群分布直觉可见，快速定位异常个体

方案 A 设计裁决要点（spec 阶段锁定依据）

总账三格瓷砖概览瓷砖语言压缩版：围栏=绿色渐变（页签身份）、在养=白卡、告警=>0 红色渐变带未读角标，=0 白卡绿字「正常」。这是围栏页与概览页最强的视觉血缘。
围栏卡片从"纯文本行"升级为卡片：4px 围栏本色色脊（与地图多边形同色）、类型标签、在养数+面积、告警胶囊（>0 红色 / =0 绿色"正常"）。停用围栏加灰色标签。
选中详情卡信息架构不变（面积/类型/在养/告警 2×2 + 编辑边界/围栏告警/删除），升级为带 elevation 的独立卡片，其余围栏 50% 透明。
对账提示沿用概览页琥珀色胶囊语言：无 GPS + 越界数 > 0 时显示，解释总账与逐栏合计的差异。
权限差异canManage=false：隐藏新建按钮与编辑/删除图标，详情卡只读展示；总账与列表不变。牧工仍可点击围栏看详情与跳转告警。
设计令牌全部继承概览页 `:root` 令牌（hero 渐变、tile-red、radius-md=12px、shadow-card/elev），新增仅 `--fence-spine-width:3px` 与 `--dim-opacity:.5`。
