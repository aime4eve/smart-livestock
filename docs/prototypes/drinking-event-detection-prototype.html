3. 数据口径在 UI 上的体现（对齐技术方案）

  • 诚实口径：详情页常驻 note-box 说明"30 分钟更新延迟 + 夏季弱信号漏检可能（检出均可靠）"——对齐方案 §7 对外口径。
  • 发热上下文：柱状图发热日染橙（--fever 低透明）+ 卡片底部 context-note 说明"发热期饮水减少属常见现象，未计入异常"——发烧抑制饮水的反向价值可视化。
  • 分层口径：屏 1 副标展示"同类均值 vs 本牛基线"双参照；屏 2 提供"本牛 / 同类均值"分段切换（对应方案 §4.2 第 5 条：统计分层不改算法参数）。
  • 基线门槛：<3 天数据不展示统计（算法需 ≥3 天有效数据），显示"基线建立中"进度态。
  • 二期预埋：饮水骤减提示条展示二期告警形态，标注"待试点验证后开放"——本期不触发。

4. 裁决记录（2026-10-04）

  • ① 语义色：水蓝 #3D7FA8（默认裁定按推荐执行）——与发情玫红/发热橙/消化棕区分度最高。
