概览 / 围栏 / 告警的分工

概览回答“牧场现在怎么样”，是状态入口：围栏、健康、设备三块只显示数量和主要矛盾。

围栏回答“空间和资产长什么样”，负责围栏形状、位置、在养数量和临近状态；这里不重复做处理队列。

告警回答“接下来该做什么”，把来自概览和围栏的风险收进四桶工作台，并锚定到牛 / 围栏 / 设备资产。

建议体验路径

左侧手机是可点击原型。所有状态都在前端内存中变化，不调用后端、不改业务代码。处理后数据会进入“今日已处理”，未读和角标同步减少。

融合验收点

① 牧场 Tab 每桶最多 3 条，能看到“现在先做什么”。② 点击桶或“查看全部”进入告警中心并保留桶上下文。③ 资产筛选不替换四桶，而是在桶内收窄。④ 点击任意卡片进入统一详情 V2。⑤ 详情底部固定主操作，处理后返回列表并同步数字。⑥ 场主/牧工看到相同风险，但操作提示不同。
