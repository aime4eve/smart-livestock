统一详情 V2 裁决点

1. 先给处置顺序，再给原始数据：风险头 → 下一步建议 → 指标 → 证据 → 生命周期。
2. “下一步建议”是固定层，不是普通文本卡；不同资产和状态只替换建议内容与主操作。
3. 证据按人话展示；评分、样本数、模型名等技术证据折叠，不进入主文案。
4. 主操作固定在底部安全区；“处理”始终比“查看详情”更醒目，角色无权限时隐藏而不是置灰。
5. 已处理详情仍保留结果、证据、生命周期，方便追溯，但不提供处理动作。
6. 四桶是顶层口径；资产筛选只是第二层，不把页面重新拆回“围栏 / 健康 / 设备”三个独立信息孤岛。
7. `DEVICE_OFFLINE` 用统一 2 小时静默阈值，恢复上报后自动解决。
8. WORKER 可处理 ACTIVE 告警；界面仍按角色隐藏越权动作。
