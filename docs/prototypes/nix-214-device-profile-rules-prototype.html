删除设备配置规则

✕
确认删除 「动物追踪器-规则链-v1-kafka 增强版」？
⚠️ 删除后，挂在此配置下的设备（如 00956906001264f1 / fa）开通校验将显示"等待 TB 设备"，无法完成开通。不影响 TB 平台上的设备与遥测数据。
删除为硬删除（配置表无业务引用，删除即失去校验资格）。警示框点名受影响设备示例，帮助管理者判断影响面。

交互规则

  • 行内启用开关：点击即保存，成功后行状态即时变化（轻提示，无弹窗）
  • 配置名唯一：新建时与已有规则重名 → 保存按钮置灰 + 行内错误提示
  • 编辑时配置名只读（改名 = 换规则，走删除重建）；类型/启停/备注可改
  • 「从 TB 刷新」：重新拉取 TB 设备配置列表，用于下拉与"配置在 TB 侧已不存在"的标记
  • 删除需二次确认；确认框点名受影响设备示例（按当前绑定该配置的本地设备数）

与开通校验的关系

  • preflight 顺序不变：NS 建档 → profile 白名单（本功能） → 遥测 key 校验
  • 替换 TbDeviceProvisioningService 中两个硬编码常量；种子迁移保证行为不变
  • 停用 ≠ 删除：停用的规则保留记录但跳过校验（可快速恢复）
  • 遥测 key 约定（result/dataHex）为平台固定协议，不在本功能管理范围

权限与入口

  • 端点：@PreAuthorize hasAnyRole('PLATFORM_ADMIN','B2B_ADMIN')（与瓦片管理一致）
  • 入口：平台管理端侧栏「设备配置」，路径 /admin/device-profile-rules
  • i18n：中英 ARB + 后端 MessageSource 双语同步
