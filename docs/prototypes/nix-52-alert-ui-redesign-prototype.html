告警重设计说明

痛点 1：操作杂乱 → 清晰有序
  • 移除硬编码 P0 假数据，全部来自真实 API
  • 状态分段控件 + 类型 chips 均可点击实时过滤
  • 每张卡片独立操作 + 批量模式
痛点 2：浏览不丝滑 → 流畅自然
  • 按日期分组，已读/未读视觉区分
  • 摘要条点击快速筛选
  • 已处理视图视觉降级
痛点 3：看不到细节 → 信息完整
  • 富信息卡片 + 详情面板含时间线和轨迹
  • 牲畜快捷面板展示健康/告警/指标

围栏管理统一设计

现状问题
  • 围栏列表藏在左侧滑出面板（FAB 切换），发现性差
  • 新增/编辑/删除分散在三个不同位置（FAB + 面板内卡片按钮）
  • 编辑围栏跳转到 /fence 而非 /fence/form?fenceId=xxx，疑似 bug
  • 地图上 FAB 太多：围栏面板切换 + 新增 + 编辑，互相干扰
方案：底部 sheet 分段 Tab
  • 牧场页底部 sheet 增加分段 Tab：概览 / 围栏 / 告警
  • 围栏 Tab：围栏列表 + 每项含编辑/删除按钮 + 顶部「新增围栏」按钮
  • 点击围栏项 → 地图高亮对应围栏 + 展开围栏详情（面积/牲畜/告警）
  • 移除：左侧滑出面板、围栏面板切换 FAB、地图上的新增/编辑 FAB
  • 围栏边界编辑仍跳转 /fence/form（修复 fenceId 传递 bug）
交互流程
  • 概览 Tab → 看板卡片「围栏告警」→ 点击切换到告警 Tab
  • 围栏 Tab → 围栏列表 → 点击围栏 → 高亮地图 + 展开详情
  • 围栏详情 → 「编辑边界」→ /fence/form?fenceId=xxx
  • 围栏详情 → 「查看告警」→ 切换告警 Tab 并筛选该围栏
  • 围栏列表 → 「新增围栏」→ /fence/form
与告警的联动
  • 围栏 Tab 围栏详情显示该围栏的活跃告警数
  • 点击「查看告警」从围栏直接跳转告警列表，预筛选该围栏
  • 告警详情面板的「所在围栏」字段可点击跳回围栏 Tab
围栏现状左侧滑出面板（FAB 切换）+ 地图右下角新增 FAB + 选中后右下角编辑 FAB + 面板卡片删除按钮。4 个不同位置，入口分散，发现性差。编辑跳转路由疑似 bug。
围栏重设计底部 sheet 围栏 Tab 统一入口。围栏列表 + 新增按钮 + 编辑/删除/查看告警一目了然。点击围栏高亮地图并展开详情。移除所有散落的 FAB，地图更干净。
