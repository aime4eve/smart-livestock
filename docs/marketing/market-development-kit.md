## 2. 切入策略与阶段（试点 → 转化 → 续费）

### 2.1 阶段总览

```
获客（demo / 询盘）→ 试点（免费试点授权，统一截止 2027-09-30）→ 试点评估 → 转化（人工合同 + 付款确认）
→ 正式订阅（ACTIVE）→ 续费（授权恢复）
```

### 2.2 试点期：免费试用统一截止 2027-09-30 是核心抓手

- 免费试点授权**全平台统一截止 2027-09-30**，截止日前按专业版（PREMIUM）能力体验，足够覆盖一个完整繁殖 / 疾病周期；越早开通免费期越长——这是催单的正当理由（2026 年内开通约免 11–12 个月，拖到 2027 年年中只剩几个月）。
- 云端新租户也可**自助开通专业版试用**（免商务流程），同一截止日。开通由我方平台运营侧执行或客户自助；已有正式订阅（ACTIVE）的租户不重复授予。
- 截止日不做个案顺延；非 ACTIVE 状态（未订阅 / 试用过期 / 已取消 / 已到期等）的租户可重新开通试点授权（仍到统一截止日），特殊诉求升级商务负责人。
- **试点设计要点**（写进试点方案，避免"装完再看"）：
  - 范围：试点动物数、设备清单、时间窗、对照组建议。
  - 成功标准必须**可验证**：告警送达率、轨迹完整率、试点动物覆盖率、响应流程闭环率；不写"提高收益 X%"这类无法验证的指标。
  - 退出条件与数据清理方式提前约定。

### 2.3 转化期：人工合同 + 付款确认

- 试用统一截止 2027-09-30，建议触达节奏：**2027-08-01 前**（截止前 60 天）首次商务沟通、**2027-08-31 前**（前 30 天）出报价与合同草案、**2027-09-23 前**（前 7 天）最终确认。
- 转化不接在线支付：签约 + 付款确认后，由我方签发正式授权，订阅恢复激活（ACTIVE）状态。
- 试点期产生的数据**保留不删除**——向客户明确"降级 ≠ 清零"，降低决策压力。

### 2.4 续费期

- 到期自动降级为基础免费版（FREE / BASIC），数据保留；续费后恢复对应档位能力。
- 把"数据在、历史轨迹在、牲畜档案在"作为续费谈判核心资产；降级期功能收窄本身就是续费动力。
- 续费动作与转化一致：合同 + 付款确认 + 授权签发。

## 3. 档位与定价建议表

> 对齐系统订阅配置（`SubscriptionTier`：BASIC / STANDARD / PREMIUM / ENTERPRISE，NIX-245 USD 按头/月 + 存栏规模分档）。**USD 全球统一、不含 VAT**；设备一次性购买 **$65/台**（客户所有），网关按牧场另报。

**软件订阅单价（$/头/月）**：

| 档位 | ＜100 头 | 100–499 头 | ≥500 头 | 数据保留 | 关键能力 | 建议客群 |
|---|---|---|---|---|---|---|
| BASIC | 免费（≤50 头） | — | — | 7 天 | 定位、基础设备管理、围栏 ≤3 | 起步 / 体验客户 |
| STANDARD | $2.60 | $2.15 | $1.40 | 30 天 | + 轨迹回放、体温监测、告警历史 | 小型牧场 |
| PREMIUM | $3.20 | $2.65 | $1.75 | 90 天 | + 发情 / 繁殖 / 疫病 / AI 异常检测 | 中大型牧场（主推） |
| ENTERPRISE | 定制（买断 ≈36 个月订阅价 + 20%/年维保） | | | 3 年 | + 集团多牧场、地端部署、定制、API | 集团 / 产业方 |

**定价话术要点**：

1. **规模分档递减**：按头计费 + 规模分档，牧场越大单头成本越低——260 头牧场 PREMIUM $2.65/头/月，500 头以上只要 $1.75/头/月；付费档无头数上限，主动帮客户算这笔账。
2. **免费试用 + 设备买断**：配套软件免费试用至 2027-09-30（统一截止日、专业版全功能），设备 $65/台一次性购买、**归客户所有**——对比竞品"硬件摊入订阅的租赁制"（如 SenseHub GO 5 年合同），我们没有硬件锁定，客户资产有残值；早开通多免几个月，是自然的催单理由。
3. **比价口径红线**：对竞品**只比 5 年总拥有成本（TCO）**——我方 ≈ SenseHub GO 的 85%（硬件 $65 + 48 个月订阅 vs 对方 60 个月全包月费），**禁止拿我方"订阅月费"直接对竞品"全包月费"比**（口径不同，客户一算硬件会觉得被套路）。**免费期按统一截止日折算**：2026 年内开通约免 11–12 个月、与"48 个月付费"口径接近；开通越晚免费期越短，报 5 年 TCO 前先按实际免费月数重算。
4. **报价拆项**：海外询盘先确认规模、设备、网络与合规，按 01 手册报价清单拆项报价（设备 $65/台 + 网关 / 订阅按头 / 实施 / 支持 / 税费 VAT）。

## 4. 竞争差异化要点

对齐方案册竞品对比表与 PRD 竞争格局（对比时遵守 01 手册竞品三原则：不贬低、不裸用数字、先看现场条件）：

| 维度 | 我方差异化 | 表达要点 |
|---|---|---|
| 通信与续航 | LoRaWAN 路线，宣传口径电池 >3 年 | 偏远牧场不依赖蜂窝；竞品多为蜂窝 / 4G，电池 6 个月–2 年（引用需标来源与日期） |
| 健康监测深度 | RBC-100 瘤胃胶囊采集体内温度 / 胃动力 | 体表设备拿不到的信号；叠加活动量形成三维联合 |
| AI 异常检测 | 无监督 + 三维联合（体温 / 蠕动 / 活动） | 与规则引擎双轨并行；不做准确率承诺（见第 5 节 FAQ） |
| 数智孪生 | 四大分析场景 + 四项行为监测覆盖全生命周期 | 竞品尚无同类组合能力（以公开资料为准，标注资料日期） |
| 行为监测深度 | 体温 / 蠕动 / 活动 / 发情随帧更新；饮水行为每日批处理（次数、时刻分布、30 日基线、同类对比 Premium） | 饮水由瘤胃体温序列推导、无需额外设备；对外只讲行为统计——异常告警为二期规划、不含饮水量、不承诺检测准确率 |
| 全球化与多租户运营 | 账号 / 手机（E.164）/ 邮箱登录、国际区号、密码策略；租户全生命周期（开通 / 停用 / 恢复）与按租户试点授权；设备 EUI 全球唯一可跨租户移交 | 海外开通不卡在手机号格式与账号体系；集团客户子租户开通 / 停用 / 恢复有产品化路径，设备调拨 / 转售不换硬件 |
| 部署形态 | 云端托管 + 地端离线授权（ONPREM） | 地端完全离线、授权绑定主机、数据不出场——数据驻留敏感客户的决定性选项 |
| 商业模式 | 设备 $65/台买断归客户 + 订阅按头/月（免费试用统一截止 2027-09-30） | 前置投入低且资产归客户；对比竞品"硬件摊入订阅的 5 年租赁锁定"模式，5 年 TCO 约为其 85%（按实际免费月数折算） |
| 设备防拆 | 防拆位随遥测上报，非法拆卸即时触发 CRITICAL 告警 | 项圈被非法摘除立即知晓，配合围栏越界构建防丢防线 |
| 统一实时状态 | 位置、瘤胃指标、健康、AI、围栏、设备、告警共用 Signal 通道；SSE 推送 + 3 秒增量轮询兜底 | 关键状态变化不用等人工下拉；弱网或推送异常时自动退回轮询，旧数据会明确标注滞后，客户不会误把过期数据当最新状态 |
| 跨资产告警闭环 | 告警按牲畜、牛群、围栏、设备聚合，用"立即处置 / 现场巡检 / 持续观察 / 今日已处理"组织 | 牧场第一眼看到的是下一步动作，而不是分散在不同模块的技术告警；牧工和老板的处置顺序天然对齐 |
| 疫病应急处置 | 接触事件、牛只风险和传播链进入处置 / 记录 / 链路三视图；一键标记病畜（选疾病类型）即时触发接触分析并进入每日接触池 | 疫情发生时回答"先隔离 / 检查哪头牛"，减少平铺记录里人工推断的时间；分级是处置紧迫度，不宣称确诊 |
| 手机 App 获取 | App 国际品牌名 **BoviScout**；Web 登录页提供 APK / IPA 下载入口，iOS 另经 TestFlight 邀请分发（构建 90 天有效期） | 试点现场少一轮"文件从哪里拿"的沟通；App Store 上架节奏不现场承诺 |
| 设备绑定管理 | 千台级设备按编号 / 序列号搜索绑定，牲畜详情页一键解绑 | 大牧场设备换绑、转售不再依赖运营后台操作，牧场主自助完成 |
| 多时区本地化 | 时间与统计按查看方时区显示（中英双语）；牧场时区按牧场 → 租户 → 平台链路继承、可按牧场单独设置；底图按牧场所在地区自动适配（中国高德 / 海外 OSM） | 海外项目的语言、时区、地图基础适配已内建，不再是"定制开发"项 |

## 5. 销售 FAQ 与异议处理

| # | 客户问题 / 异议 | 应答要点 |
|---|---|---|
| 1 | **数据安全怎么保障？** | 多租户三级隔离、角色分权、API Key 按 scope 授权且密钥哈希存储、关键操作审计留痕。地端部署数据完全留在客户内网。追问合规认证 / 数据驻留细节时，按 01 手册转产品 / 合规负责人，不口头承诺。 |
| 2 | **能不能完全离线部署？** | 可以。地端独立部署（ONPREM）：离线镜像整包交付、运行不依赖公网、离线授权文件签名校验并绑定主机指纹、数据不出场。适合集团 / 政府客户。 |
| 3 | **AI 准确率多少？** | 不承诺准确率数字。AI 健康评分为试点能力、持续迭代；与规则引擎双轨并行，AI 不可用时自动静默降级、不影响定位围栏告警主链路。效果用客户现场真实数据的试点评估来验证。 |
| 4 | **价格贵 / 比竞品贵** | 不陷入单纯比价：① 按 5 年 TCO 比——我方 ≈ 主流竞品全包订阅的 85%，且**设备归客户所有**（竞品多为硬件摊入月费的租赁制，5 年后设备还是厂商的）；② 规模越大单头越便宜（≥500 头 PREMIUM $1.75/头/月）；③ 用客户自己的丢失损失、人工巡查、空怀天数数字做价值量化（价值公式见 00 赋能手册）；④ 免费试用至 2027-09-30 + $65/台设备是唯一前置投入，先验证再付费。**注意比价口径：只比 5 年总成本（按实际免费月数折算），不拿我方订阅月费对竞品全包月费。** |
| 5 | **到期后会怎么样？会不会删数据？** | 到期自动降级为基础免费版，**数据保留不删除**，牲畜档案与历史数据完整；续费（人工合同 + 付款确认）后立即恢复对应档位能力。没有任何自动扣款风险。 |
| 6 | **部署要多久？** | 云端托管：开通即用，设备入网与培训按实施计划。地端部署：离线镜像 + 脚本化安装 + 健康检查，标准环境可按天级完成，具体周期按现场环境评估后承诺（不现场拍数字）。 |
| 7 | **必须买你们的硬件吗？已有设备能用吗？** | 功能有设备依赖：围栏 / 轨迹需 GPS 追踪器，温度 / 蠕动需瘤胃胶囊，健康评分 / 发情检测需两者齐备。客户已有设备先收集型号、厂商、数据格式做兼容性评估（按 01 手册），不假设"都能接"。 |
| 8 | **能和我们现有系统对接吗？** | 提供 Open API：牲畜 / 围栏 / 告警 / 设备只读查询，API Key 鉴权 + scope 授权 + 限流 + 租户隔离。具体数据对象、频率、安全策略走技术评估（01 手册第 9 节升级），不当场承诺接口清单。 |
| 9 | **牧场网络信号差怎么办？** | LoRaWAN 免蜂窝覆盖（宣传口径 5–10 公里半径）、设备数据多级容错、App 断线保留最近数据并标注滞后、恢复自动对账。**离线作业（离线地图 / 围栏 / 缓存）尚未上线，禁止对外宣传**，客户追问时如实说明在路线图上、时间不承诺。仍需现场勘测网关位置与覆盖（01 手册硬件售前检查清单）。 |
| 10 | **牧工不会用智能手机 / 不愿意用** | 牧工端界面只聚焦地图、告警、确认三个动作；处理与归档由牧场主完成；培训按角色拆分（01 手册 Demo 结构）。 |
| 11 | **海外用时区 / 语言 / 地图对得上吗？** | 界面中英双语；时间与日 / 小时统计按查看方时区显示，牧场时区按牧场 → 租户 → 平台链路继承、可按牧场单独设置；地图底图按牧场所在地区自动适配（中国高德，海外 OSM），海外牧场开箱即用。小语种翻译与当地底图细节按项目技术评估（不当场承诺）。 |
| 12 | **手机 App 怎么安装？** | App 国际品牌名 **BoviScout**。Android：Web 登录页下载 APK 直接安装。iOS：TestFlight 邀请安装（构建 90 天有效期，到期更新新构建即可），Web 登录页 IPA 入口仅限登记设备验证；不承诺 App Store 上架节奏。批量交付方式按合同与实施计划确认。 |
