## 1. 方案定位与价值（Positioning & Value）

SmartLivestock 智慧畜牧是一套端到端的牲畜智能管理平台，通过 **IoT 设备（GPS 项圈追踪器 + 瘤胃胶囊 + 智能耳标）+ 数智孪生平台 + AI 分析**，实现牲畜**定位管控、健康预警、行为分析**，帮助牧场从经验养殖走向数据驱动的精准养殖。

**核心价值主张**：

| 价值 | 说明 |
|---|---|
| LoRaWAN 低功耗广覆盖 | 偏远牧场不依赖蜂窝网络，覆盖半径 5–10 公里；设备电池寿命长（宣传口径 >3 年），一次安装长期免维护 |
| 数智孪生差异化 | 发热 / 消化 / 发情 / 疫病四大 AI 分析场景，覆盖牲畜全生命周期 |
| AI 无监督异常检测 | 体温 + 蠕动 + 活动三维联合分析，规则引擎与 AI 双轨并行 |
| 防盗能力 | 项圈追踪器与耳标 / 胶囊蓝牙关联，链路异常主动上报丢失告警 |
| 离线全功能作业 | 离线地图瓦片、离线围栏与牲畜缓存，弱网环境不中断，网络恢复自动同步 |
| 灵活部署与订阅 | 云端托管或地端独立部署；免费版起步，可选订阅，不强制月费 |

## 2. 目标场景（Target Scenarios）

**牧场规模**（以牛、羊等反刍畜种为主）：

| 客户类型 | 规模 | 核心需求 |
|---|---|---|
| 小型牧场 | 50–200 头 | 定位防盗、基础健康 |
| 中型牧场 | 200–1,000 头 | 繁殖管理、疾病预警 |
| 大型牧场 | 1,000–5,000 头 | 全面管理、降本增效 |
| 超大型 / 集团 | 5,000 头以上 | 集团化管理、数据分析、系统集成 |

**典型区域**：中国内蒙古 / 新疆等大范围放牧区域；国际市场覆盖阿根廷（潘帕斯草原）、巴西（中南部）、南非、澳大利亚、新西兰等蜂窝覆盖有限、依赖人工巡查的牧区。

**典型痛点**：人工巡栏耗时、疾病发现滞后、牲畜走失盗窃、偏远牧场网络覆盖差。

## 3. 三位一体能力（Three-in-One Capability）

### 3.1 IoT 感知层

| 设备 | 采集能力 |
|---|---|
| GAT-100 GPS 追踪器（项圈式） | GPS 位置、步数、三轴加速度、电量 |
| RBC-100 瘤胃胶囊（吞服式） | 瘤胃温度、胃动力、三轴加速度、电池状态 |
| 智能耳标 | 牲畜身份标识，支持蓝牙关联防盗 |
| LoRaWAN 网关 | 目的国频段适配、现场覆盖、数据转发 |

### 3.2 数智孪生平台

- 地图实时监控、历史轨迹回放、热力图分析
- 电子围栏：手绘多边形 / 模板创建，越界实时告警，分时段策略
- 告警工作台：`待处理 → 已确认 → 已处理 → 已归档` 全流程闭环，牧场主 / 牧工分工协作
- 牲畜数字档案：耳标、品种、体重、设备绑定、健康记录一体化
- 多租户、多牧场、多角色（牧场主 / 牧工 / 集团管理端 / 平台运营端）

### 3.3 AI 分析引擎

- 四大健康分析场景：发热早期检测、消化功能分析、发情智能识别、疫病趋势预警
- 无监督异常检测：STL 节律剥离 + CUSUM 突变检测，体温 / 蠕动 / 活动三维联合评分
- AI 能力边界与降级机制见第 8 节声明。

## 5. 部署形态（Deployment Options）

同一平台提供两种交付形态，按**信任边界**划分而非物理位置：

| | 云端托管（HOSTED） | 地端独立部署（ONPREM） |
|---|---|---|
| 交付方式 | 注册开通即用，我方负责运维、监控与升级 | 离线镜像整包交付至客户机房，脚本化安装 |
| 运行环境 | 我方托管的云环境 | 客户内网，运行**不依赖公网** |
| 数据归属 | 平台多租户隔离，按租户严格隔离 | 数据完整保留在客户内网，**数据不出场** |
| 授权方式 | 在线开通试点授权 / 订阅 | 厂商签发的离线授权文件（`.sllicense`），Ed25519 数字签名 |
| 主机绑定 | 不要求 | 授权绑定安装 ID + 主机指纹，防拷贝迁移 |
| 传输安全 | HTTPS | HTTPS（TLS 1.2/1.3），80 端口强制跳转 |
| 适用客户 | 快速启动试点、中小规模牧场、希望零运维 | 对数据驻留、离线运行有严格要求的集团 / 政府 / 大型牧场 |

说明：部署在我方运营的服务器上（即使物理上位于客户指定机房）仍属云端托管；只有服务器交付给客户、客户持有管理员权限的环境，才属地端独立部署。

### 6.2 365 天试点授权（市场测试期核心权益）

- 市场测试期内，由我方为客户**开通 365 天试点授权**。
- 试点期内按**专业版（PREMIUM）能力**体验，便于完整评估健康监测与 AI 分析价值。
- **到期自动降级**为基础免费版（FREE / BASIC）：仅开放免费层能力，**已产生的数据完整保留、不删除**，可随时续费恢复。
- 试点授权由平台运营侧开通，可延长、不可缩短；已有正式订阅的租户不重复授予。

### 6.3 续费模式

- 续费通过**人工商务合同 + 付款确认**完成，签约付款后由我方签发正式授权，恢复激活（ACTIVE）状态与对应档位能力。
- 不接入在线支付；订阅变更、续费、取消均以合同为准。
- 地端部署客户：续费后获取新的离线授权文件，导入即恢复，无需重装系统。

### 6.4 地端离线授权机制（ONPREM）

- 授权文件 `.sllicense` 采用 Ed25519 数字签名，包含租户、档位、有效期与资源配额（牲畜 / 围栏 / 牧工 / 设备）。
- 授权绑定安装 ID 与主机指纹，导入前校验当前用量不超过授权配额。
- 内置**时间回拨保护**：检测到系统时间异常回拨时进入保护模式，防止授权篡改。
- 到期后系统降级为基础能力并保留数据；导入续期授权后立即恢复。

## 7. Open API 与生态（Open API & Ecosystem）

Open API 是本方案的核心能力之一，面向集团内部系统、集成商与产业平台：

- **鉴权**：API Key 独立认证（与用户登录态分离），密钥以哈希存储，支持创建、吊销与过期管理。
- **授权范围（scope）**：按 Key 粒度授权数据范围，最小化披露。
- **限流**：每分钟请求数 + 每日调用配额双重限制，超限返回明确错误码。
- **租户隔离**：API 只能访问其授权租户的数据，与其他租户严格隔离。
- **能力范围**：牲畜、围栏、告警、设备的只读查询，以及调用统计与用量趋势。
- **开发者门户**：API 文档、Key 审批与用量看板。

API 访问按订阅档位与授权配置开放，具体范围以合同为准。已有系统（ERP、养殖管理系统、监管平台）可通过 Open API 完成数据集成；接口兼容性需技术评估后确认。

## 8. AI 能力边界声明（AI Capability Boundary）

为保证客户预期一致，特此声明：

1. **试点能力**：AI 健康评分与无监督异常检测为试点（pilot）能力，处于持续迭代阶段，本方案**不承诺准确率指标**。
2. **辅助定位**：AI 分析用于辅助健康决策，**不替代兽医诊断**与人工管理决策。
3. **数据前提**：异常检测依赖个体遥测数据积累（个体基线约需 14 天数据），数据不足时自动回退规则引擎与群体基线。
4. **静默降级**：AI 服务不可用时系统**自动跳过 AI 分析**，规则引擎照常运行；定位、围栏、告警等主链路不受任何影响。
5. **效果评估**：真实效果以客户现场真实数据的试点评估为准，不以仿真数据作为生产效果承诺。
